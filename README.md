# LoanShield — Transparent Financial Credit Scoring & Risk Analytics

LoanShield is an academic Streamlit prototype for exploring credit-risk prediction, model explainability, customer segmentation, and evaluation using the **UCI German Credit dataset**.

> **Research-use warning:** this project is not a real lending system. Its model is trained on a small, historical dataset and has not been calibrated or validated for present-day lending. Do not use it to approve or reject real applications. SHAP explanations are explanations of model behaviour, not causal claims or proof of creditworthiness.

## Included modules

1. **Customer Assessment** — 20 German Credit input fields, saved Random Forest inference, predicted Bad Credit probability, and an individual SHAP contribution chart/table.
2. **SHAP Audit** — global mean absolute SHAP importance and per-customer contribution distributions.
3. **Customer Segmentation** — K-Means with `k=3`, PCA projection, cluster profiles, and observed Bad Credit prevalence per cluster.
4. **Model Evaluation** — held-out test metrics, confusion matrix, ROC and precision-recall curves, plus five-fold CV comparisons for Logistic Regression, Random Forest, and RBF-SVM.

## 1. Environment setup (WSL / Ubuntu)

Run commands from the project root:

```bash
cd ~/LoanShield
python3 -m venv venv
source venv/bin/activate
python -m pip install --upgrade pip
pip install -r requirements.txt
```

Python 3.11 is recommended. If you already have a virtual environment, activate it instead of creating another one.

## 2. Generate credit model and evaluation artifacts

The source dataset is included at `data/raw/german.data`. The training script makes a stratified 80/20 split using `random_state=42`. The preprocessor is fitted only on the training partition; the 200-row held-out test set is not used to fit the model.

```bash
python -m src.models.train_credit_model
```

This creates:

- `models/credit/random_forest.joblib`
- `models/credit/preprocessor.joblib`
- `models/credit/feature_names.joblib`
- `models/credit/model_metadata.json`
- `reports/results/final_test_metrics.json`
- `reports/results/final_test_predictions.csv`
- `reports/results/model_comparison_cv.csv`
- `data/processed/X_test.csv` and `y_test.csv`
- confusion matrix, ROC and PR curve images under `reports/figures/`

**Important:** running this command trains a reproducible model from the included dataset. It does not recover the exact binary model artifact from a different machine. If you already have your previously frozen `random_forest.joblib` and `preprocessor.joblib`, back them up before running this training command; you may copy those existing files into `models/credit/` instead.

## 3. Generate customer segmentation

```bash
python -m src.clustering.kmeans
```

This generates `models/credit/kmeans.joblib`, `cluster_scaler.joblib`, `cluster_pca.joblib`, and CSV outputs under `reports/results/`.

The selected `k=3` follows the project's exploratory segmentation design. It is a descriptive grouping, not a supervised risk classification. Review silhouette/DB diagnostics before drawing conclusions.

## 4. Launch the dashboard

```bash
python -m streamlit run app/streamlit_app.py
```

Streamlit prints a local URL, usually `http://localhost:8501`.

## 5. Tests and checks

```bash
python -m pytest -q
python -m compileall -q app src tests
```

## Model interpretation

- Original target label `1` is mapped to `0 = Good Credit`.
- Original target label `2` is mapped to `1 = Bad Credit`.
- Probability shown by the app is `predict_proba(...)[class 1]`.
- The default classifier threshold is 0.5; the displayed class is the model's threshold-based output.
- Positive SHAP contributions push the model output toward the Bad Credit class; negative contributions push it away.
- Global feature importance aggregates contribution magnitude over a sampled set. It is not a causal effect.

## Troubleshooting

- **Missing `.joblib` files:** run the credit training command or restore your previously saved model artifacts.
- **`ModuleNotFoundError: src`:** run the Streamlit command from the LoanShield project root.
- **SHAP memory/runtime:** lower the sample-size slider on the SHAP Audit page.

## Dataset note

The included `german.data` file is the original whitespace-delimited German Credit dataset used by the project. Check the dataset's distribution/usage terms before redistributing the project publicly.
